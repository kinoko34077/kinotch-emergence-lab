# KiNoTch. Cross-Repository Emergence Lab

A public, research-first workspace for finding and evaluating **synergy, composable capabilities, knowledge transfer, and genuinely emergent possibilities** among KiNoTch. repositories.

This is not another portfolio manager, generalized executor or replacement for devflow. It investigates what combinations can accomplish that isolated projects cannot, and records the evidence, tradeoffs and validation plans before any separate implementation is authorized.

## Research directions
- Development experience and verified judgment feedback across repositories
- Reusable interoperable capability composition
- Japanese text, glyph, input and presentation interoperability
- Music, lyrics, subtitles and visual production workflows
- Artificial-life / language-model cross-experiment learning
- Knowledge navigation and interactive experience composition

## Strict scope exclusion
**`kinoko34077/map-data-semi-automation` is excluded entirely.** Do not inspect, import, index, analyze or connect that repository, its Issues or any associated data. Existing devflow-managed scope exclusions remain in effect.

- [devflow](https://github.com/kinoko34077/devflow): cross-repo execution/control policy and coordinated Work Orders.

No private files, credentials, personal conversation exports, user-specific local content, business data or raw sensitive repository contents. Cross-repository analysis remains read-only until a separate explicit execution instruction and applicable safety gates. No license is presumed.
