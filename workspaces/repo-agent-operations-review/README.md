# リポジトリ群・エージェント運用レビュー：資料ワークスペース

既存リポジトリ群の現状、およびAIエージェントを使った開発・監査・運用の課題を、別AIが資料に基づき分析し、対策を検討するための資料置き場。

- [materials/](materials/)：利用者が後から提供する関連資料の置き場。**現時点でレビュー対象の資料は未投入。**
- 資料の記述、実際に確認できた現行状態、AIの推論・仮説・対策案は区別する。
- 現行状態を判断する際は、必要に応じてliveの[devflow](https://github.com/kinoko34077/devflow)と対象リポジトリの正本を確認する。このワークスペースへの資料配置は、元の正本の変更や廃止を意味しない。

## 公開範囲・権限

このリポジトリは **Public**。機密・資格情報・非公開リポジトリの内容・個人情報・業務情報・私的会話を含む資料は置かない。非公開資料は元の許可された環境で管理し、公開可能な参照情報のみ扱う。

既存の研究仕様に従い、`kinoko34077/map-data-semi-automation` は資料配置・調査・分析の対象から完全に除外する。`pc-files` と `pc-files2` の既存の非管理・プライバシー境界も維持する。

このディレクトリの設置は、別AIへの分析依頼の実行、対策の採用、他リポジトリの書き換え、権限・秘密情報・公開設定の変更を許可するものではない。

設置記録：[Issue #3](https://github.com/kinoko34077/kinotch-emergence-lab/issues/3)。
